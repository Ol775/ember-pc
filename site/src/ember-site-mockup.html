About

A fan and lighting app that stays out of your way.

Ember started because PC control software is usually loud: bloated, cloud-linked and always asking for an account. This is one calm window that reads your sensors, runs your fans and lights your desk, and keeps everything on your own machine.

Local only

No accounts and no telemetry. The only network use is what you switch on, such as checking GitHub for an update.

Safe by default

Fan limits are enforced in a separate service. The app only displays and asks, so closing or crashing it never touches a fan.

Open source

MIT licensed and built in the open by one person, Ol775. Read the code, report a bug, or help test the betas.

Safety

Fans never stop when the CPU is hot.

Fan speeds are written only by the service, only for headers you have tested and enabled.

90°

On any source, every controlled fan goes to 100%. Released at 85°.

30%

Floor for the CPU, and for the GPU fan. System fans never drop below 20%.

100%

A missing or stale sensor sends the affected fans to full speed.

0

Bytes sent on its own. No accounts, no telemetry.

Install

Three steps, about a minute.

Needs Windows 10 or 11 (x64) and administrator rights. The installer adds .NET 8 if it is missing.

Download

Get Ember-Setup-<version>.exe from the latest release. Betas are marked Pre-release.

Run the installer

Accept the Terms, follow the pages. It adds the services and a signed driver, checked before it runs. Windows shows an unknown publisher warning because the installer is not code-signed yet.

Test one fan header

Open Fans, test a System Fan header, then enable it. Nothing is written to a fan header before you do.

Questions

Before you install.

Is Ember free?

Yes. It is open source under the MIT licence, with no accounts, no ads and no paid tier.

Which versions of Windows does it need?

Windows 10 or 11 (x64) and administrator rights to install the services and the driver. The installer adds the .NET 8 runtime if it is missing.

Which lights and devices does it work with?

Govee, Philips Hue, Nanoleaf, Razer Chroma, Logitech G HUB, Meross bulbs and light strips, and anything OpenRGB supports. Tapo and Meross plugs are read for power draw only. The integrations page lists them all.

Why does the Power page say my motherboard has no sensor?

No motherboard reports how much power it uses. CPU and GPU report their own watts. For the rest, Ember reads a smart plug on your PC and subtracts CPU and GPU. Without a plug it shows CPU and GPU only.

Why are some of my fans at 0 RPM in Super quiet?

Some fans stop below about 20% speed. Pick Quiet, or use Manual to set a higher minimum.

Is it safe to run?

Fan control has unit tests and has been checked on one real PC, and the safety rules above are enforced in the service. Test one header at a time and watch your temperatures.

Does it work on my motherboard?

It is built and tested on an MSI B550-A PRO. Other chips supported by LibreHardwareMonitor may work. The verification page lists what has been checked.

Will it switch my smart plugs?

No. It only asks a plug what it is drawing.

Does it send data anywhere?

Not on its own. The only network use is what you switch on, such as update checks against GitHub.

Can I use it with SignalRGB or NZXT CAM?

Not at the same time on the same devices. Ember warns you about fan-control programs by name and can close them.

Give your PC a calmer window.

Free, open source and local only. Download it, test one fan header, and watch the temperatures settle.
